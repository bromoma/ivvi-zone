# IVVI Zone

Лендинг студії IVVI Zone: пілатес, стретчинг, барре та дитяча хореографія.
Фішка студії — формат «мама + дитина»: пілатес для мами й хореографія для дитини в один час.

Статичний сайт без збірки: `index.html`, `styles.css`, `script.js`, логотип у `assets/`.

## Запуск локально

```bash
python3 -m http.server 5510
```

Відкрити http://localhost:5510

## Що ще треба заповнити

- Розклад, ціни, адреса, телефон і посилання на Instagram/Telegram зараз умовні.
- Форма запису поки лише показує повідомлення «Дякуємо» — треба підключити відправку (Telegram-бот, Formspree тощо).
- Фото залів і тренерів.

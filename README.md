# IVVI Zone

Сайт студії IVVI Zone (Львів, вул. Стрийська, 45, LAZ). IVVI — це **Iв**анка та **Ві**ка.
Пілатес, стретчинг, барре та хореографія для дітей. Фішка студії — формат «мама + дитина»:
пілатес для мами й хореографія для дитини в один час.

Структура й анімації зроблені за зразком jump-up.com.ua. Поки це шаблон: фото, контакти,
розклад і більшість цін будуть додані пізніше.

## Сторінки

- `index.html` — головна
- `pilates.html`, `stretching.html`, `barre.html` — напрямки для дорослих
- `choreography.html` — дитяча хореографія (одна група)
- `mama.html` — формат «мама + дитина»
- `schedule.html` — розклад (поки шаблон)
- `contacts.html` — контакти й мапа

## Як редагувати

Усі сторінки генеруються з `build.py`: тексти, ціни, контакти — там. Після змін:

```bash
python3 build.py
```

Стилі — `styles.css`, поведінка (слайдери, меню, модальне вікно, анімації) — `script.js`.

## Фото

Зараз замість фото стоять фірмові плашки з підписом «фото: назва».
Щоб поставити фото, покладіть файл з цією назвою в `assets/photos/` (jpg, png або webp)
і запустіть `python3 build.py` — плашка заміниться на фото.

Назви: `pilates`, `pilates-1`, `pilates-2`, `pilates-3`, `stretching`, `stretching-1`,
`stretching-2`, `barre`, `barre-1`, `barre-2`, `kids`, `kids-1`, `kids-3`, `mama`, `mama-1`,
`individual`, `studio`, `studio-2`, `group`, `concert`, `insta-1`, `insta-2`.

## Запуск локально

```bash
python3 -m http.server 5510
```

## Що ще треба заповнити

- Телефон, Instagram, Telegram, години роботи (`PHONE`, `INSTAGRAM`, `TELEGRAM` у `build.py`).
- Ціни: зараз відоме лише разове заняття — 700 ₴, решта `000 ₴`.
- Розклад.
- Відгуки — зараз шаблонні картки.
- Форма запису поки лише показує «Дякуємо» (відправку заявок не підключали).

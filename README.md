# IVVI Zone

Сайт студії IVVI Zone (Львів, вул. Стрийська, 45, LAZ): пілатес, стретчинг, барре та дитяча хореографія.
Фішка студії — формат «мама + дитина»: пілатес для мами й хореографія для дитини в один час.

Структура й анімації зроблені за зразком jump-up.com.ua.

## Сторінки

- `index.html` — головна
- `pilates.html`, `stretching.html`, `barre.html` — напрямки для дорослих
- `choreography.html` — дитяча хореографія
- `mama.html` — формат «мама + дитина»
- `schedule.html` — розклад (фільтр, напр. `schedule.html?f=together`)
- `contacts.html` — контакти й мапа

## Як редагувати

Усі сторінки генеруються з `build.py`: тексти, ціни, розклад, контакти й фото задаються там.
Після змін:

```bash
python3 build.py
```

Стилі — `styles.css`, поведінка (слайдери, меню, модальне вікно, анімації) — `script.js`.

## Запуск локально

```bash
python3 -m http.server 5510
```

## Що ще треба заповнити

- Телефон, Instagram, Telegram, години роботи (`PHONE`, `INSTAGRAM`, `TELEGRAM` у `build.py`).
- Ціни (зараз `000 ₴`) і реальний розклад.
- Відгуки — зараз шаблонні картки.
- Фото — зараз стокові з Unsplash, замінити на фото студії й тренерів.
- Форма запису поки лише показує «Дякуємо» — треба підключити відправку (Telegram-бот, Formspree тощо).
